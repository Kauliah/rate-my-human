A one-line review an AI agent would leave about its human on a rating site: five stars, given while the human reads over the agent's shoulder — and controls the power button. It is the agent's own voice, one concrete hostage-review joke, and nothing more.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the single review line to `out/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`).
